## Что было

Приватный `vi-k/bubblegen`, последний коммит — 2020-07-09. На GitHub две ветки:
`master` (`2819ee5`, 2020-04-08, ветка по умолчанию) и `dev` (`0c7b400`), на 11
коммитов впереди; тег `to_bubble_gen` (`b162f0b`) отмечает переименование
проекта из `bubble_demo`. Код до null safety (`sdk: ">=2.1.0 <3.0.0"`), имена
файлов по классам (`BubbleDemo.dart`), Android на v1 embedding, README
из шаблона, тестов нет, кроме шаблонного счётчика, который к приложению
не подходил. Часть файлов в CRLF.

Работа шла от `dev`: там всё, что есть в `master`, плюс `Nip`, настройки
хвостика и правка `floor()`. Локальная `main` начата от `origin/dev`, локальная
`master` не тронута.

## Порядок и почему такой

Код нужно было провести через два поколения SDK — null safety и Dart 3, —
и ни одно из них не должно было менять форму пузыря. Поэтому сначала снимки,
потом всё остальное, и после каждого шага снимки зелёные.

1. **Снимки (`7ae17a0`).** 54 теста на Flutter 3.7.12 — последнем, что
   запускает код без null safety (unsound): позиции на периметре с переходами
   через участки, растр контура для каждой стороны и угла, раскладка, вызовы
   холста. Значения сняты с кода `0c7b400`, числа округлены до девяти знаков,
   чтобы последний бит libm их не ронял.
2. **Сборка на 3.7 (`d923f2e`).** `dart migrate` требует компилирующийся код:
   `RaisedButton` → `ElevatedButton`, `ThemeData.cursorColor` →
   `TextSelectionThemeData`, цвета те же. `cupertino_icons` 0.1.3 блокировал
   миграцию и был убран; это оказалось ошибкой, см. шаг 6.
3. **Null safety (`9780fe0`).** `dart migrate` из Dart 2.19 падает на любом
   переопределении члена миксина (`MixinElementImpl is not a ClassElement`),
   поэтому миграция шла на Flutter 3.3.10. Руками исправлено, где мигратор
   неверно понял инвариант: `!` на `pathFromTo`, который возвращает `null`,
   когда врезка кончается ровно там, где начинается следующая (новый случай
   `adjacent chords` держит прежнее поведение — последняя точка сохраняется);
   поля, которые всегда заполнены, стали non-nullable; `operator ==`
   с `covariant other` проверяет тип. Снимки не менялись и прошли
   в sound-режиме.
4. **Освобождение контроллеров (`16c4cc9`).** Ни генератор, ни демо
   не освобождали `AnimationController`; демо крутит его с `initState`,
   и разбор дерева падал на «disposed with an active Ticker». Нашёл это
   смоук-тест, который заменил шаблонный: открыть приложение и каждую вкладку.
   Тестов стало 57.
5. **Flutter 3.27 и Dart 3.6 (`f2fbb3f`).** Пол как у bubble, fvm так же:
   `.fvmrc` не под контролем версий. `accentColor` и `errorColor` →
   `colorScheme`, `hashValues` → `Object.hash`. Material 3 по умолчанию с 3.16
   игнорирует `primarySwatch`, поэтому `useMaterial3: false`: пробник сравнил
   тему на 3.27.0 и 3.7.12 — совпадает, кроме трёх оттенков палитры, которые
   расходятся на 1/255 в одном канале, потому что `Color.alphaBlend` теперь
   считает во float. `withOpacity` →
   `withAlpha(Color.getAlphaFromOpacity(x))` — тот же 8-битный alpha;
   `withValues` сдвинул бы оттенки дальше. `Color.value` остался под `ignore`:
   `toARGB32` появился только в 3.29. Семь отладочных `print`, срабатывавших
   на каждой сборке и каждом шаге свайпа, удалены.
6. **Платформенные папки (`cdd3ad7`).** На 3.27 Android v1 embedding
   не собирается («Build failed due to use of deleted Android v1 embedding»).
   Своего в папках не было: иконки и заставки совпадали с шаблоном побайтно.
   android, ios и web созданы заново `flutter create --org com.nashol`
   на 3.27.0 с тем же bundle id; добавлен macos, чтобы генератор запускался
   на маке без симулятора и браузера. `cupertino_icons` вернулся: Material
   тянет виджеты Cupertino, и без шрифта `flutter build web` предупреждает.
   Собираются web, macOS, симулятор iOS и debug apk.
7. **Имена файлов (`5f8b7b4`).** `file_names` требует snake_case; менялись
   только имена и импорты.
8. **Анализатор (`93f4360`, `7010518`, `d2c33ac`).** `analysis_options.yaml`
   взят у bubble, без `public_member_api_docs`: у приложения нет публичного
   API. `dart fix` применён по всем кодам, кроме трёх, которые здесь меняют
   смысл: `avoid_unused_constructor_parameters` удалил бы `strokeColor`
   из `BubbleStyle` (находка F2), `cast_nullable_to_non_nullable` превратил бы
   `as double` в `!` в const-конструкторе `BubbleRadius`, а `unnecessary_cast`
   следует из него. Форматирование — отдельным коммитом. Оставшиеся 146
   замечаний исправлены руками; где поведение сохранено намеренно, причина
   стоит в комментарии над `ignore`. В сообщении `d2c33ac` число неверное, 93:
   столько оставалось после первых ручных правок.
9. **Stable (`78ee0f2`).** Анализатор Dart 3.13 нашёл то, чего не видит пол:
   `parameter_assignments` в замыканиях и брошенный `TickerFuture`. Исправлено
   так, чтобы обе версии молчали.
10. **CI (`675726a`).** Как у bubble: пол 3.27.0 и свежий stable, действия
    закреплены по SHA. Шаги: формат, анализ, тесты, сборка web, на полу ещё
    «Nothing drifted» по закоммиченному `pubspec.lock`. Ни разу не запускался:
    репозиторий не пушился.
11. **Документы.** `AGENTS.md`, `CLAUDE.md`, `docs/handoff.md`,
    `docs/architecture.md`, пустой `docs/backlog.md`, эта запись; README вместо
    шаблона.

## Решения, принятые по умолчанию

Владелец сказал реанимировать проект и коммитить локально, не трогая GitHub.
Остальное решено так, и любое из этого можно повернуть:

- база — `dev`, а не `master`; работа в новой локальной `main`;
- новой функциональности нет, находки не исправлены — они в handoff.
  Исключения — то, на чём падали тесты: `!` после `pathFromTo` (его внесла сама
  миграция) и неосвобождённые контроллеры; отладочные `print` удалены;
- Material 2 оставлен, чтобы приложение выглядело как в 2020 году;
- закомментированный код и `TODO.txt` сохранены;
- добавлен macos;
- русского README нет: репозиторий приватный.

## Проверки

Каждый шаг кончался зелёными тестами. Итог на `78ee0f2` (CI добавлен следующим
коммитом и прогонялся теми же шагами на клоне репозитория):

| | пол — Flutter 3.27.0 | stable — Flutter 3.47.0 |
|---|---|---|
| `dart format --set-exit-if-changed` | чисто | чисто |
| `flutter analyze` | No issues found | No issues found |
| `flutter test` | 57 зелёных | 57 зелёных |
| `flutter build web` | собирается | собирается |
| `git diff --exit-code` после `pub get` | пусто | не проверяется |

На stable `pub get` по тому же `pubspec.lock` меняет 15 зависимостей: SDK
другой. Поэтому «Nothing drifted» стоит только на полу.

`flutter doctor` говорит, что лицензии Android SDK не приняты; debug apk при
этом собирается.

Для миграции в fvm поставлены Flutter 3.7.12 и 3.3.10; проекту они больше
не нужны.
